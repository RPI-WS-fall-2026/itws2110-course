# In-class

Tuesday in-class exercises are released here, one directory per session.

- [Week 5 — React, starting small](wk5/README.md): micro-installation, Tailwind-based
  drills, state and props, and composition with shadcn/ui.
- [Week 6 — where state lives, and how to prove it](wk6/README.md): keys, lifting state,
  derived state, composition; then component tests with Vitest and Testing Library.
- [Week 7 — what a framework buys you](wk7/README.md): routes, views, escaping and layouts in
  Laravel; then controllers, named routes, 404s and the request object. Runs with Docker Compose Watch.
- [Week 9 — Eloquent: models, migrations, relationships](wk9/README.md): a migration, queries,
  casts, belongsTo, hasMany, the N+1 problem and belongsToMany, in a Laravel app with MySQL.
- [Week 11 — security: find it, then fix it](wk11/README.md): SQL injection, XSS, CSRF, a
  committed secret, a vulnerable dependency, and security headers, in a Laravel app with MySQL.
