# In-class

Tuesday in-class exercises are released here, one directory per session.

- [Week 5 — React, starting small](wk5/README.md): micro-installation, Tailwind-based
  drills, state and props, and composition with shadcn/ui.
- [Week 6 — where state lives, and how to prove it](wk6/README.md): keys, lifting state,
  derived state, composition; then component tests with Vitest and Testing Library.
- [Week 7 — what a framework buys you](wk7/README.md): routes, views, escaping and layouts in
  Laravel; then controllers, named routes, 404s and the request object. Runs with Docker Compose Watch.
- [Week 9 — Eloquent: models, migrations, relationships](wk9/README.md): a migration, queries,
  casts, belongsTo, hasMany, the N+1 problem and belongsToMany, in a Laravel app with MySQL.
- [Week 11 — security: find it, then fix it](wk11/README.md): SQL injection, XSS, CSRF, a
  committed secret, a vulnerable dependency, and security headers, in a Laravel app with MySQL.
- [Week 12 — the login lab](wk12/README.md): add register, log in, log out and `GET /user` to
  your team's `api/`, with a curl check script. Friday 11/13; the start of Homework 9.
  Then [the login drills](wk12/laravel/README.md): seven holes in the to-do app's login to
  break and fix, and an eighth drill that writes the access rule once, as a policy, each with
  a Check result button.
  And [the React starter kit, running](wk12/react-starter/README.md): the one-app Inertia
  shape from Friday's slides, with a Students page to follow from route to screen.
- [Week 13 — a front end in a bucket](wk13/bucket/README.md): the midterm pantry prototype
  built to plain files and served from cloud storage, with three predictions to check with
  `curl`. Shown live, Tuesday 11/17.
- [Week 13 — the deploy drills](wk13/laravel/README.md): four changes that get the to-do app
  ready for strangers (debug off, a health route, a start that keeps the data, trusting the
  proxy), then the app's production image (FrankenPHP,
  PostgreSQL) on your laptop. Tuesday 11/17; the push is participation. Friday 11/20 is team
  time on [Homework 10](../homework/hw10/README.md), which puts your project on Azure.
